# Macro examples

This directory contains the preserved `original-passing/` macro inputs and
their `expected/` output transcripts, the `run_examples.py` comparison runner,
and a current-Cwhip macro input (`cwhip-syntax.txt`) with its exact expected
expansion (`cwhip-syntax.cw`).

See [Examples](../doc/EXAMPLES.md) for provenance, commands, syntax coverage,
and comparison rules.
